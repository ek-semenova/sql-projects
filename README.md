# SQL Projects — Нетология

Учебные проекты и задания по SQL в рамках курса ML-инженер (Computer Vision), Нетология.

## Содержание
- Домашние задания по SQL
- Итоговый проект по SQL

## Навыки

**Выборка данных:** SELECT, WHERE, ORDER BY, LIMIT, DISTINCT

**Типы данных:** числовые, строковые, дата/время, массивы, JSON/JSONB, булев тип

**Агрегация:** SUM, COUNT, AVG, MIN, MAX, GROUP BY, HAVING

**Соединения таблиц:** INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL JOIN, CROSS JOIN

**Множественные операции:** UNION, EXCEPT, INTERSECT

**Подзапросы:** скалярные, табличные, IN, EXISTS, NOT EXISTS

**Управление структурой БД (DDL):** CREATE, ALTER, DROP, ограничения и ключи

**Управление данными (DML):** INSERT, UPDATE, DELETE
